## Week 2
The base of this is a very simple clicker game, but the unique thing is that all visitors collaborate to collect the clicks.  
It is intentionally designed in a way that makes inflation less likely by making every singular click be a separate http request. This also makes it a bit taxing on the cpu if many upgrades are purchased, but that's the player's problem.

This is reachable either at [https://clicker.olio.ovh] (Separated because I didn't want my central proxy server or the main host be bothered by having people spam it)

The backend is simple python for both of these, the frontend has htmx and javascript for interactivity.
